# Base Cases

Place user provided OpenFOAM base case directories here.

Research specific base cases used during development are intentionally excluded
from this public repository. A base case should contain the OpenFOAM
directories, dictionaries, and run scripts required by its campaign.

Set `paths.base_case` in the campaign JSON to the selected base case directory.
A small synthetic example is available in `examples/demo_base_case/`.
